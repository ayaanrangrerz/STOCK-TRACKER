# Stock Portfolio Tracker (Python)

A command-line exercise that totals a sample portfolio using a built-in table of stock prices.

## Run
Requires Python 3. No third-party packages are needed.

```bash
python "STOCK TRACKER.PY"
```

Enter a listed ticker and a positive whole-number quantity. Enter `done` to finish; the program shows subtotals and the total, then offers to save a text or CSV summary.

## Important
Prices are hard-coded examples, not live market data. This tool is for programming practice and must not be used for investment decisions.
